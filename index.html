What resources are needed

Three main things are needed: an Alpaca (brokerage) account, Visual Studio Code (to implement the code), and Python environment







Step 1: Create an Alpaca account

  1. Go to https://alpaca.markets/stocks
  2. Create an account.
  3. Verify your account using multi-factor authentication (MFA).

The reason why you need to do this: Alpaca is a brokerage that has a paper trading feature, which also allows for the use of API keys, so trading can be automated.







Step 2: Download Visual Studio Code

  1. Go to the Visual Studio Code website: https://code.visualstudio.com/download
  2. Download the installer for your operating system.
  3. Run the installer and follow the setup instructions.

The reason why you need to do this: Visual Studio Code will help you write and manage your Python code more effectively. It's an IDE (Integrated Development Environment).







Step 3: Download the following Python extensions on Visual Studio Code

  1. Python
  2. Pylance
  3. Python Debugger
  4. Python Environments
  5. autopep8

The reason why you need to do this: This will help format your Python code to conform to the PEP 8 style guide, compile your code and help fix it easily.

  1. Go to the official Python website: https://www.python.org/downloads/

def moving_average(df):
    df["sma_fast"] = df["close"].rolling(window=5).mean()
    df["sma_slow"] = df["close"].rolling(window=20).mean()

    latest_fast_average = df["sma_fast"].iloc[-3:]
    latest_slow_average = df["sma_slow"].iloc[-3:]

    if all(latest_fast_average > latest_slow_average):
        return "buy"
    elif all(latest_fast_average < latest_slow_average):
        return "sell"
    else:
        return "hold"


def alpaca_order(decision, symbol, quantity):
    positions = {p.symbol: p for p in api.list_positions()}
    pending_orders = api.list_orders(status="open")

    if decision == "buy" and symbol not in positions and symbol not in [o.symbol for o in pending_orders]:
        api.submit_order(symbol=symbol, qty=quantity, side="buy",
                         type="market", time_in_force="gtc")
    if decision == "sell" and symbol in positions:
        api.submit_order(symbol=symbol, qty=quantity,
                         side="sell", type="market", time_in_force="gtc")
