Why would it would be beneficial for the user to implement their own code?

  • The user will get more coding experiences
  • The user would need to use their own API key to connect to their Alpaca account, so telling the user to put in their API key into the website would be unsafe.
    • NOTE: API keys need to stay private because if a threat actor gains access to the keys, they can cause data breaches and financial losses
  • The user will have more control over which stock companies to invest in
